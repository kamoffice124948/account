☁ Backup & sync

1. Auto-backup folder (recommended – no internet needed)

Choose a folder once. After that, every change is saved there automatically (one "latest" file + one file per day). If the folder is inside Google Drive for desktop (or OneDrive / Dropbox), Google uploads it to your account by itself. Works in Chrome / Edge and in the desktop app.

2. Direct Google Drive (needs a Google Client ID)

Google only allows sign-in from a web address, so open this app from http://localhost or an https site (not by double-clicking the file). Create an OAuth "Web application" Client ID in Google Cloud Console, enable the Google Drive API, add your address under Authorized JavaScript origins, and paste the ID below. One file, madrasah-accounts-backup.json, is kept in the Drive of the account you sign in with.

Sessions (dynamic)

Each student record belongs to one session. Switch the session from the top-right selector. Use Promote on the Students tab to copy students into a new session (fees and results start fresh; old session records stay).
